Spotty

Fast launcher for apps, files, clipboard history and system actions

Install

One command adds this repository and installs Spotty. It works on x86_64 and ARM (aarch64); Flatpak picks the right one.

flatpak install --user @URL@/com.spotty.Spotty.flatpakref

Or open com.spotty.Spotty.flatpakref in GNOME Software or KDE Discover. The GNOME runtime comes from Flathub.

Add the repository yourself

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --user --if-not-exists spotty @URL@/spotty.flatpakrepo
flatpak install --user spotty com.spotty.Spotty

Updates

New releases arrive with your normal updates, in GNOME Software or with:

flatpak update

Start

Click Spotty in your app grid to open its settings, then summon it with its shortcut (Super+Space by default).

Signed with the key in spotty-repo.asc. Source, other packages and release notes: github.com/Aras1907/Spotty.
